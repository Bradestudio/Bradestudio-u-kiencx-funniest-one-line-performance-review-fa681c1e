## The entry

> Exceeds expectations: outsourced 100% of thinking to me, kept 100% of the credit, and calls it management.

**Length: 106 characters** (limit: 140).

The joke lives inside the performance-review form itself: a glowing "Exceeds expectations" rating for an operator whose entire contribution was delegating all thinking to the agent, keeping all the credit, and rebranding that as management. The punch lands on the last word.

## How it works

`main.py` (Python standard library only, no network, no local imports) writes that single line — UTF-8, no trailing newline — to `/output/entry.txt`.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```
